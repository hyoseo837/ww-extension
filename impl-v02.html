Key v01 architectural decisions to preserve

  • page-bridge.js runs in page context to access dataViewerApp, getPostingOverview, action tokens. Content script ↔ page bridge via postMessage with reqId namespacing.
  • Bridge bypasses getPostingOverview() and hits /myAccount/co-op/full/jobs.htm directly with cached tokens — kills the overlay flicker during scans. Don't revert this.
  • MutationObserver on the <table> (not <tbody>) with rAF-debounced wipe+reinject of badges — DataViewer reuses <tr> elements on page change, in-place badges would leak otherwise.
  • WW pagination puts active / disabled / aria-label on the inner <a class="pagination__link">, not the <li>. scrollToRow's helpers operate on the <a> directly.
  • Pagination anchors are <a href="javascript:void(0);"> — use dispatchEvent(new MouseEvent('click', …)) not .click() or CSP fires on the javascript: URL.
  • background.js validates Gemini response shape (score 1–10, verdict ∈ {Apply, Consider, Skip}, reason non-empty); returns structured {ok, code, error} with code ∈ {NETWORK, RATE_LIMIT, HTTP, PARSE, SHAPE}.
  • Gemini 2.5 Flash thinking mode is disabled (thinkingConfig: { thinkingBudget: 0 }) — thinking tokens otherwise eat the maxOutputTokens budget.
