v02 Vision

v01 proved the workflow but the candidate context is weak: it's a single hand-typed textarea. v02 raises the quality of that context (PDF upload + AI extraction, soft preferences) so scoring decisions are sharper. Further v02 features are TBD and will be added here as the user confirms them.

Confirmed v02 features

v02.001 — Profile from PDF + Preferences

Replace the single plain-text cvText popup field with two structured inputs:

  1. Application package PDF upload. WaterlooWorks lets students export a combined PDF containing résumé, grade report, and co-op work history. The popup accepts that single PDF, sends it to Gemini's multimodal endpoint with an "extract as plain text" prompt, and populates an editable textarea with the result. The textarea remains the source of truth — the user can clean it up before saving, or skip the upload entirely and type from scratch.
  2. Preferences textarea. A free-form soft-constraints field ("prefer Waterloo, Toronto OK, no San Francisco; backend or data roles only"). Stored separately and included in the Gemini scoring prompt as its own labelled section, omitted entirely when empty so users who don't fill it pay no token cost.

Full design notes for v02.001 live at ~/.claude/plans/tidy-orbiting-nova.md. Read that before implementing.
