How to Use
  1. Go to API Configuration and paste your Gemini API key. Click Save.
  2. Go to Profile & Context, drop in your application package PDF (from WaterlooWorks Documents), click Extract Profile, then Update Profile.
  3. Optionally add Custom Match Criteria (e.g. "Remote only, no Web3") to sharpen scoring.
  4. Navigate to the WaterlooWorks jobs list, click the purple AI Score tab on the right edge, then hit Scan All Jobs.
