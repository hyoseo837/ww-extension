Backend API Contract

Placeholder. Populated when v4.1 backend bootstrap lands. This file is the authoritative contract — endpoints, request/response shapes, error codes, auth headers — for the FastAPI backend in server/. Single source of truth; no mirror. The client (extension) reads this file directly.

Backend lives at server/ in this repo (monorepo since ADR 0010 superseded 0004). The packaging boundary between client and server is enforced by package.sh excluding server/ from the Web Store zip.

Auth header convention (planned, v4.2)

Authenticated endpoints will expect the Supabase session JWT in Authorization: Bearer <jwt>. Backend verifies the JWT against Supabase JWKS before any business logic.

Anticipated endpoints (subject to phase planning)

GET /health (v4.1)
Liveness probe. No auth.
GET /me (v4.2)
Authenticated. Returns current user identity + credit balance.
GET /credits/balance (v4.3)
Authenticated. Returns current credit balance.
POST /scan (v4.4)
Authenticated. Submits a posting payload; backend forwards to Gemini, debits one credit, returns {score, verdict, reason}.
POST /credits/checkout (v4.5)
Authenticated. Creates a Stripe Checkout session for credit purchase; returns the checkout URL.
POST /webhooks/stripe (v4.5)
Stripe-only (signature-verified). Receives checkout.session.completed; grants credit idempotently on Stripe's event ID.
