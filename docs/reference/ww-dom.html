Note on scoped attributes: DataViewer renders elements with scoped Vue attributes (data-v-612a1958, data-v-5e323a0e, etc.). These are stripped for readability in the snippets below. To inherit DataViewer's CSS on injected cells, add data-v-612a1958="" to injected <th> and <td> elements.

All three POST to /myAccount/co-op/full/jobs.htm using jQuery's $.post (session cookies are sent automatically). Action tokens are session-specific — extract fresh on each scan, never cache or hardcode.

4. Action Token Shape and Extraction

Every WaterlooWorks action uses a session-specific token with prefix _-_- followed by a base64url payload ([A-Za-z0-9_-]). Lengths range ~195–215+ chars. Tokens are always object-literal values (e.g. action: '_-_-...'), never bare var x = '_-_-...'.

Extraction strategy: scan all inline <script> elements (those without a src attribute), search for the function/property name that owns the token, then capture the adjacent token. Extraction regexes:

// Extract selectAll token:
/onSelectAll[\s\S]{0,400}?action:\s*['"](_-_-[A-Za-z0-9_-]+)['"]/

// Extract getPostingOverview token:
/function\s+getPostingOverview[\s\S]{0,400}?action:\s*['"](_-_-[A-Za-z0-9_-]+)['"]/

// Generic: capture any token adjacent to a known name:
/FUNCTION_OR_PROP_NAME[\s\S]{0,400}?(_-_-[A-Za-z0-9_-]+)/

9. Pagination and Re-render Signals

DataViewer replaces the entire <tbody> on sort, filter, page change, and explicit dataViewerApp.$dataViewer.refresh() calls. There is no exposed page-change event.

MutationObserver target: observe the <table> element inside #dataViewerPlaceholder (not just <tbody>, which may itself be replaced) with { childList: true, subtree: true }. Re-inject AI Score badges in the observer callback whenever new tr.table__row--body elements appear.

Pagination controls use ul.pagination__list and li.pagination__item; the active page item has class active disabled. Page size is user-selectable: 25 or 50 (default 50, set via itemsPerPage: 50 in dataViewerProps).
