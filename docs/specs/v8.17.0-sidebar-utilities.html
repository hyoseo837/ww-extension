v8.17 — Sidebar utilities: web-app shortcut & scan backup

Goal

Two small whiteboard features for the extension sidebar (owner call, 2026-06-16): a one-click shortcut to the web app, and export/import of the scored set as a file (move between devices / backup). Both are extension-only — no server or web-app change.

  1. Web-app shortcut icon (v8.17.1) — an icon button in the sidebar header, next to the gear (Settings), that opens the web app. It targets /account — the user's hub (balance, history, profile) and the same destination the toolbar action already opens (background.js chrome.action.onClicked). Reuses the existing openWebApp message (chrome.runtime.sendMessage({ type: 'openWebApp', path: '/account' })).
  2. Scan export / import (v8.17.2) — per ADR 0054: a compact Export / Import row in the sidebar controls.
    • Export — serialise all scores (both boards) + postingIds into { app, schema, exportedAt, scores, postingIds } and download ww-scores-YYYY-MM-DD.json via a Blob + <a download>. Disabled when there are no scores.
    • Import — a hidden <input type="file" accept=".json">; read with file.text(), JSON.parse. Reject a malformed / non-ww file or a schema mismatch (≠ SCORING_SCHEMA_VERSION, the ADR 0016 guard) with a progress-line error. Otherwise show a confirm dialog that warns current scores for shared posting ids will be replaced by the file's (data-loss warning), then merge (imported wins on collision), union the postingIds, saveScores(), renderSidebarList(), and injectRowScores() so the open tab updates live.

Files

  • ext/src/sidebar.css — style the header icon button to match #ww-ext-settings; the Export/Import row to match the existing controls.
  • ext/manifest.json — version bumps.

Verify

  • node --check passes on every touched ext/src/ file.
  • Owner manual pass (live WW): the header shows the web-app icon next to the gear; clicking it opens /account in a new tab. With some scores, Export downloads a .json; clear scores, then Import that file → the warning dialog appears → confirm → the scores and row badges come back. Import on top of existing scores merges (file wins on shared ids). A non-JSON / wrong-schema file is rejected with a message and leaves current scores untouched.

Notes

  • Export is a content-script Blob download — no downloads permission, so the manifest's permission set is unchanged.
  • Import live-updates only the tab it runs in; other open WW tabs pick the merged set up on their next load (the storage write is shared, but the content script only reloads scores on init).
