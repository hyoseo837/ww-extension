v6.7.0 — Collect the extension into ext/

Goal

Move the Chrome extension's source out of the implicit repo root and into a dedicated ext/ folder, so it is a symmetric peer of web/ and server/ (ADR 0026). Pure restructure — no extension code or behavior changes. Internal manifest references survive untouched because manifest.json, src/, and icons/ move together (Chrome resolves them relative to the manifest). Release tooling (package.sh) and output (dist/) stay at the repo root, repointed at ext/.

Files

Moved (git mv) — into ext/

  • manifest.json → ext/manifest.json
  • options.html → ext/options.html
  • welcome.html → ext/welcome.html
  • src/ → ext/src/ (content, background, page-bridge, options, welcome, sidebar.css)
  • icons/ → ext/icons/
  • design/ → ext/design/ (extension UI mockups — distinct from web/design/)
  • screenshots/ → ext/screenshots/ (Web Store listing assets)

Changed

  • package.sh (stays at root) — read version from ext/manifest.json; cd ext before zip so the archive keeps manifest.json at its root; write the zip to the root dist/ (same allowlist: manifest, options.html, src/, the three icons).
  • ext/manifest.json — version bump to 6.7.0.
  • docs/architecture.html — Client section: paths noted as relative to ext/; link to ADR 0026.
  • CLAUDE.md — Build/package + orientation: load ext/ as unpacked; ext/manifest.json is the version source.
  • README.md — icon/screenshot image paths, the architecture file tree, and the "Load unpacked → select the ext/ folder" step.
  • Dev-load memory — updated to "load ext/".

Not changed (deliberately)

  • dist/ location, .gitignore (its dist/ and *.zip rules still hold).
  • docs/archive/** and past per-phase specs — frozen history; their root-relative paths were correct at the time.
  • The zip allowlist contents (welcome.html remains out of the zip exactly as before — packaging behavior is preserved, not "fixed" here).
  • web/, server/ — untouched, so no Vercel/DO rebuild is triggered by this commit.

Verify

  1. ./package.sh builds dist/ww-extension-v6.7.0.zip; unzip -l shows manifest.json, options.html, src/*, and the three icons at the archive root (no ext/ prefix) — i.e. a Chrome-loadable zip.
  2. chrome://extensions → Load unpacked → select ext/ loads and scans exactly as before.
  3. git mv preserved history (git log --follow on a moved file walks past the move).
  4. No living doc still tells a reader to load the repo root; archived docs are unchanged.
