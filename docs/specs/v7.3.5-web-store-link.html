v7.3.5 — Web Store link (landing + dashboard)

Goal

Now that the extension is published (v7.2), surface a link to the Chrome Web Store listing from the web app so visitors and signed-in users can install it. Web-app-only change; no decisions.

Files

  • web/src/links.ts — new: CHROME_STORE_URL single source for the listing link.
  • web/src/pages/Landing.tsx — secondary "Add to Chrome — it's free" button in the hero, under the sign-in CTA.
  • web/src/Layout.tsx — "Chrome Web Store" item in the dashboard sidebar nav (next to the WaterlooWorks link); shows on the dashboard and every signed-in page.
  • ext/manifest.json — version bump (repo-wide version is the manifest, ADR 0002), even though the change is web-only.

Verify

  1. Logged-out landing hero shows "Add to Chrome" linking to the store listing (new tab).
  2. Signed-in: the dashboard sidebar shows a "Chrome Web Store" link.
  3. tsc / web build passes.
