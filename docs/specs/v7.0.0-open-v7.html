v7.0.0 — Open v7: archive v6, extension/Web-Store direction

Goal

Open major version 7. v6 shipped the UI transition — the account / profile / payment surface rebuilt as a web app, plus the admin surface, legal/trust pages, and the data-subject rights (export + deletion). It is feature-complete and frozen. v7 turns back to the Chrome extension: make it (a) work cleanly against that web app (website integration) and (b) pass Chrome Web Store review so it can be re-published — the gate before going live on Stripe and actually monetizing.

This phase is pure docs, following the v6.0.0 precedent: archive v6 per ADR 0014, flip the roadmap, and open v7. The detailed scope — the extension↔web integration model and the specific compliance fixes — lands in the per-phase specs (and an ADR) when each phase opens, not here.
