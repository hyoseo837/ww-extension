v6.8.0 — Web type-scale tune-down + sidebar email wrap

Goal

The Stitch type scale rendered too large on real screens — page titles (display-lg 48px) and sidebar wordmark felt oversized; the app only looked right at ~75% browser zoom. Shrink the whole scale at the single source (the Tailwind fontSize tokens, used by every page) and let the sidebar email show in full instead of truncating. No layout/spacing or behavior changes — fonts only. Tunes the tokens from ADR 0023; the token approach is unchanged, so no new ADR.

Files

  • web/tailwind.config.js — fontSize reduced ~75–80%, headings hit hardest: display-lg 48→34, display-lg-mobile 32→26, headline-lg 32→24, headline-md 24→19, body-lg 18→16, body-md 16→14, label-md 14→13, label-sm 12→11 (line-heights scaled to match; letter-spacing kept).
  • web/src/Layout.tsx — sidebar email truncate/text-label-md → break-all/text-label-sm so the full address shows (wraps if long) instead of clipping.
  • ext/manifest.json — version bump to 6.8.0.

Verify

  1. cd web && npm run build clean.
  2. At 100% zoom the app reads like the old ~75–80%: page titles ("Match Preferences", "Welcome back"), the sidebar "WW Scorer", and the admin headings are visibly smaller; body text stays readable (14px).
  3. The full email shows in the left sidebar (no "…" clipping).

v6.8.1 — further tune-down + spacing + sidebar nav

Follow-up after review: still felt a touch large and too airy, and the sidebar was missing two useful links.

  • web/tailwind.config.js — fontSize reduced again (display-lg 34→30, display-lg-mobile 26→24, headline-lg 24→21, headline-md 19→17, body-lg 16→15, body-md 14→13, label-md 13→12, label-sm 11). Spacing tightened ~0.75 (xs 8→6, sm 12→9, md 16→12, lg 24→18, xl 32→24, xxl 48→36, gutter 24→18); base (4px) and max-width (960px) kept. The sidebar width uses Tailwind's built-in w-64/ml-64/ left-64, not these tokens, so alignment is unaffected.
  • web/src/Layout.tsx — desktop sidebar nav gains Preferences (/preferences, icon tune) and an external WaterlooWorks link (the jobs page where the extension runs, opens in a new tab). Mobile top bar unchanged (space-constrained).
  • ext/manifest.json — version bump to 6.8.1.

Notes

Revises ADR 0024. That ADR decided Preferences would not be a top-level nav item (reached only from the dashboard snapshot / Profile). v6.8.1 adds it to the sidebar at user request — a minor IA change, recorded here rather than as a superseding ADR; promote to one if the nav set is re-litigated.

The Stitch export docs (web/design/.../DESIGN.md) still list the original sizes/spacing as a historical record; tailwind.config.js is the live source.
