ADR 0037 — Drop the v8 extension JavaScript→TypeScript migration

Context

On 2026-06-01 the extension JS→TS migration was pulled out of v7 and scheduled as its own major, v8 (roadmap), to bring the extension to TypeScript for parity with the web app (ADR 0019). That scheduling was always hedged: the roadmap itself notes v8 has zero Web-Store-review benefit, adds a build step, and would supersede the no-build packaging of ADR 0026 — so it was deliberately placed after approval and monetization, not blocking them.

As of v7.5 the extension is approved, published, and working in production as plain JavaScript: no build step, ext/ loads unpacked, package.sh zips it directly. The one motivation for v8 was cross-codebase parity, an internal nicety with no user- or review-facing payoff.

Decision

  • Cancel v8 as a planned major. The extension stays JavaScript. The no-build packaging of ADR 0026 stands — nothing supersedes it.
  • TypeScript scope remains the web app only (ADR 0019), unchanged.
  • The idea is not forbidden, only de-committed: it moves to the roadmap's "Further out (uncommitted)" candidates. Reopening it would take a future ADR that shows a concrete payoff (e.g. a build step earning its keep some other way).

Consequences

  • The extension keeps its zero-dependency, no-build workflow — the simplest thing that ships, and the thing that already passed Web Store review.
  • The JS and TS halves of the monorepo stay stylistically split (web = TS, ext/ = JS). Accepted: the boundary is a clean client/API split (the extension is a thin profile reader + in-page scorer), not shared code, so the parity gain was cosmetic.
  • No type-checking safety net is added to the extension. Accepted at its current size; revisit if the extension grows materially.

Alternatives considered

  • Keep v8 planned — status quo before this ADR; spends a whole major on an internal refactor with no user benefit while the product works.
  • Migrate incrementally inside a later phase — still forces the build step / ADR 0026 reversal for no review or product gain; same objection, smaller blast radius. Rejected for the same reason.
