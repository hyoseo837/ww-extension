ADR 0014 — Relocate shipped major-version specs to docs/archive/vNN/

Context

v4 (Monetization) shipped, and v5 has phase-started. Under ADR 0005, per-phase specs live in docs/specs/ and docs/archive/ held only the v01–v03 plan/impl/history triad, marked "do not extend." That left no defined home for a shipped major version's specs: docs/specs/ accumulated all eight v4 spec files mixed in with the active v5 spec, and the only "done" signal was each spec's status meta.

The question at major-version close: leave shipped specs in docs/specs/ (a flat, ever-growing pile), or relocate them so docs/specs/ shows only the active version. ADR 0005's archive policy didn't cover this because v01–v03 predated the spec shape entirely.

Decision

When a major version ships and the next opens, relocate its per-phase spec files into docs/archive/vNN/, kept in their original spec format (not converted to the old plan/impl/history triad). v04 is the first to follow this: the eight v4.*.html specs now live in docs/archive/v04/.

This amends the archive policy of ADR 0005. Unchanged by it:

  • ADRs stay immutable in docs/decisions/ — they are cross-cutting and subject-indexed, not version-scoped, so they do not move.
  • Living docs (roadmap.html, architecture.html, reference/) stay in place and keep spanning versions.
  • Relative links are fixed on relocation. Moved specs sit one level deeper, so their up-links (../decisions/ → ../../decisions/) are repointed, and inbound links from other docs are updated to ../archive/vNN/…. Where an inbound link lives in an immutable ADR, repointing the path is treated as link maintenance (the decision text is untouched), not a substantive edit.

Consequences

  • + docs/specs/ shows only the active major version — less noise when working a current phase.
  • + docs/archive/ becomes the uniform home for every frozen major version, not just the pre-spec ones.
  • + Specs keep their format, so an archived v04 spec reads exactly as it did when shipped (unlike the v01–v03 triad).
  • − Relocation breaks relative links until fixed; closing a major version is now a deliberate move-and-repoint step, not just a status flip. This ADR records the procedure so it's mechanical next time.
  • − docs/archive/ now holds two doc shapes: the v01–v03 triad and v04+ specs. docs/README.html notes the split.
  • − An immutable ADR (0012) carries a mechanically repointed link to a relocated spec. Acceptable: the link target is the same document, only its path changed.
