v7.3.2 — Sidebar restyle + per-score delete

Goal

Bring the in-page WaterlooWorks sidebar up to the warm-editorial design sheet (ext/design/extension_sidebar_job_scan/) and add the two score-list affordances the owner asked for: a per-card ✕ to delete a single score, and a confirmation on the destructive "Clear" button. This is the second slice of the v7.3 redesign (v7.3 spec); it converts the sidebar to light-mode-only per ADR 0032.

Design fidelity constraints

  • No remote resources (ADR 0030): the design sheet links Tailwind, Source Serif 4, and Material Symbols from CDNs. Port the look into local sidebar.css; self-host Source Serif 4 as a woff2; use inline SVG in place of the Material Symbols font.
  • Keep the real scale (ADR 0017): the mockup shows single digits; ship the 1–20 score + the six-verdict ladder (Strong Apply / Apply / Consider / Unlikely / Skip / Excluded). The mockup's three filter pills were illustrative — keep all six.

Files

Changed

  • ext/src/sidebar.css — rewrite to a single warm-editorial light token set (cream #fff8f0 page, white surfaces, maroon #8f4830 primary, warm borders). Drop the dark :root / .ww-light dual tokens (ADR 0032). New card layout: score circle + verdict pill + folder + ✕; serif headings via a self-hosted @font-face; body in Inter.
  • ext/src/content.js — new card markup (score circle, org under title, folder + ✕ buttons); a removeScore(id) that deletes one entry from the scores map + storage + its table badge; a confirmDialog() reused for a "Clear all N scores?" prompt; drop the theme plumbing (applyThemeToContent, the theme change-listener, the saved-theme read — ADR 0032) and the residual model storage read (always Flash — ADR 0031). Header text → "WW Scorer"; drop the header help (?) button (how-to lives in the empty-state guide).
  • ext/fonts/source-serif-4.woff2 — new self-hosted font (latin subset, variable weight).
  • ext/manifest.json — version bump; add the woff2 to web_accessible_resources for the WW host so the content-script-injected @font-face can load it.

Verify

  1. On a live WW jobs page the sidebar matches the design: cream panel, maroon "WW Scorer" serif header, score circle + verdict pill cards, warm borders; renders in light only (no theme toggle, no dark tokens).
  2. Each card has a folder button (save) and a ✕ that removes only that score — from the list, the cached scores, and the inline table badge — leaving the rest intact.
  3. "Clear" now prompts for confirmation; cancel keeps the scores, confirm clears all (existing clearScores behavior).
  4. A scan still scores 1–20 with six verdicts; the /scan request carries no user-chosen model (Flash).
  5. grep -rn "fonts.googleapis\|cdn\|tailwindcss.com\|ww-light\|applyThemeToContent\|settings.model" ext/src → none in shipped files.
  6. ./package.sh zips fonts/source-serif-4.woff2 and excludes design/.

Notes

  • Residual theme / model storage keys left by older builds are now read nowhere; no migration needed (display-only state) — closes the cleanup deferred from v7.3.0.
