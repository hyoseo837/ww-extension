v6.3.0 — Web design system (Tailwind) + restyle existing pages

Goal

Open v6.3 by applying the Stitch "Warm Editorial" design to the web app: adopt Tailwind with the exported theme config (ADR 0023) and restyle the existing surfaces (layout, account, billing, buy, history, landing) to match. This establishes the design system before the UI-heavy profile/preferences pages are built (v6.3.1+), so they're written already in-style rather than restyled later. The Stitch export lives in web/design/ as reference (outside the build).

Files

Added — web/

  • tailwind.config.js — the Stitch theme (colors, fontFamily, fontSize, spacing, borderRadius); content globs; forms + container-queries plugins.
  • postcss.config.js — tailwindcss + autoprefixer.

Changed — web/

  • package.json — add tailwindcss (v3), postcss, autoprefixer, @tailwindcss/forms, @tailwindcss/container-queries.
  • index.html — Google Fonts links (Inter, Source Serif 4, Material Symbols).
  • src/index.css — replace the hand-rolled baseline with @tailwind base/components/utilities + minimal base styles.
  • src/Layout.tsx — top nav (wordmark, route links with the active underline, credit pill, avatar initial, sign out) + footer, per the export's nav/footer pattern.
  • src/pages/Account.tsx, Billing.tsx, Buy.tsx, Landing.tsx, src/HistoryList.tsx — Tailwind utilities matching the Stitch screens. Buy keeps the real packages (500/$5, 1000/$10, 2000/$20); only the visual style comes from the design (no "Save %" tiers).

Verify

  1. cd web && npm run build is clean (Tailwind compiles; no TS errors).
  2. Deployed: account / billing / buy / landing match the Stitch screens — warm ivory bg, terracotta #8f4830 primary, Source Serif 4 headings, soft cards, sticky nav with active-link underline.
  3. Functionality unchanged: balance pill, credit history (incl. grouped "Scanned N jobs"), and the Stripe buy round-trip all still work.
  4. Responsive: cards stack and nav collapses sensibly on a narrow window.

Notes

Tailwind v3, not v4 — the Stitch config is v3 JS format, so v3 ports verbatim (ADR 0023).

Landing stays minimal here — a styled hero only; the full logged-out landing (the landing_page_logged_out export) is v6.5.

Next (v6.3.1+): build /profile (CV upload + experiences/projects) and /preferences (match criteria) — the candidate_profile_cv_experience and match_preferences Stitch screens — in this style. The extension sidebar restyle (reusing these tokens) is deferred to after the v6.4 slim-down. Admin (admin_dashboard) is v6.6.
