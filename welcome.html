Welcome!

AI-powered job scoring for WaterlooWorks. Get set up in 3 steps.

1
Get a Gemini API key (paid)
Get a key from Google AI Studio. A paid API key is required — the free tier is limited to 5 requests/min and 25 requests/day, which is not enough to scan a full job board.
2
Paste your API key and upload your application package
Open Settings (button below), go to API Configuration to save your key, then go to Profile & Context and drop in your application package PDF (downloadable from the WaterlooWorks Documents page). The AI uses your profile to score each job's fit.
3
Go to WaterlooWorks and scan
Navigate to the co-op jobs list, click the purple AI Score tab on the right edge of the page, then hit Scan All Jobs.
